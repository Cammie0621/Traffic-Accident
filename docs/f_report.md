# F｜主要肇因與車種年齡

## 操作

1. 安裝 `requirements.txt` 的依賴後，執行 `python -m streamlit run app.py`，從左側開啟「肇因與當事者」。
2. 在側邊欄選年度、縣市、A1／A2，再用頁面的「車種篩選」更新三張圖。正式報告前確認頁面顯示 2021–2025 的完整資料範圍。完整資料的下載與放置方式請見 [README](../README.md#完整清理資料下載)。
3. 在肇因圖選 Top 5、10、15 或 20。圖下方可核對目前事故總件數、圖上顯示件數與「未知／未填」件數。
4. 在直方圖切換「排除待覆核年齡」時，箱型圖會同步更新。展開箱型圖下方的表格，核對各車種類別有效人次加總與直方圖的「可分析年齡」。

## 統計口徑與 Trace Code

| 圖表 | 資料與計算 | 讀圖方式 |
| --- | --- | --- |
| 主要肇因水平長條圖 | 以所選車種的當事者找出事故 ID，回事故表計算不重複事故，按警方研判的 `main_cause` 大類分組。多車種採聯集。跨年同義標籤「駕駛人／駕駛者」及「無(車輛駕駛人因素)／無(車輛駕駛者因素)」各合為一類。「行人(或乘客)」與「非駕駛者」保留原分類。空值與空字串併入「未知／未填」並參與排名，無效年齡不影響計案。 | 橫軸是件數。Top N 限制顯示類別數，所有符合事故仍計入圖下方的總件數。 |
| 車種年齡箱型圖 | 使用同一頁選出的當事者，直接沿用 A 直方圖目前採用的有效年齡列，以 `vehicle_type` 分組。 | 中間線為中位數，箱體由 Q1 至 Q3，四分位距為 Q3 − Q1。鬚到達距箱體 1.5 倍四分位距內最遠的實際年齡。離群點仍為有效觀測值，同車種、同年齡合成一點，提示中顯示人次。少於 10 人次的類別以警語提醒。 |

程式順序為 `load_data()` → `render_sidebar_filters()` → 篩出 `vehicle_part` 和 `vehicle_acc` → `render_causes()` → `render_age()` → `render_vehicle_ages()`。A 的年齡模組使用既有的人員、年齡及待覆核規則，並把實際繪入直方圖的年齡及資料索引傳給箱型圖。

## 完整資料觀察

以下為 2021–2025 五年、六都、A1／A2、全車種，保留待覆核年齡時的結果。

- 「駕駛者」合併同義標籤後為 1,065,640 件，在 1,309,477 件推定事故中排名第一。「其他」有 168,915 件。
- 機車當事者的年齡中位數為 35 歲，Q1–Q3 為 24–52 歲，共 1,653,013 人次。小客車為 44 歲，Q1–Q3 為 33–56 歲，共 699,236 人次。在這兩類中，機車當事者的中位數較低，四分位距較大（28 歲與 23 歲）。
- 各類箱型圖有效年齡合計 2,799,962 人次，可和預設直方圖的「可分析年齡」核對。

## 分析限制

- 肇因排行反映警方研判分類和本專題的資料範圍。事故件數受交通量、行駛里程與車種使用量影響，這些資料未用於校正。
- 箱型圖呈現事故紀錄中當事者的年齡。乘客依原分類呈現，無法推定乘坐車種。同一人可能因不同紀錄而出現多次。
- 樣本少的類別對單筆資料較敏感。遇到離群點，可以查看該年齡對應的人次並比較待覆核選項。
