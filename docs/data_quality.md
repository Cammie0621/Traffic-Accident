## 案件識別與重複處理

先以原始日期、時間、事故類別、警局、地點及經緯度形成候選鍵，再驗證來源當事者順位與同案傷亡、城市、主要肇因一致性。

有 23 組候選鍵包含多次順位 1；在原始順序中分成不同案件後，同案共用欄位皆一致。若只把時間、地點或座標相同視為同案，這些事故會被誤合併。分案規則依賴來源順序，來源改版後必須重新驗證。出現無起始順位 1、無效順位或同案共用欄位衝突時，程式停止產出，要求核對來源。

另有 1 個案件的 2 列紀錄順位重複，但當事者內容不同；保留所有列，以獨立 participant_id 識別。沒有根據年齡或事故欄位相同而刪除不同當事者。

## 年齡與非人紀錄

人的來源紀錄 588,245 列；明確非人紀錄 30,308 列。來源屬性明示的無或物及無人駕駛紀錄保留在當事者表，但不進入人的年齡分布。

年齡採可辨識的人、可解析的 0–120 整數；120 是本專案檢查門檻，不宣稱為官方年齡碼定義。負值未轉成 0，不依推測把 114 等值換成年齡，也沒有用平均值補年齡。

## 日期時間 地點與座標

日期無效案件 0，時間無效案件 0。保留前導零並解析午夜，不因時間無效刪除整案。

城市優先依地點開頭的行政區名稱，必要時由警局補判，兩者可判定時交叉核對。本批六都資料無城市衝突；不是行政市界的空間套疊驗證。

座標以經度 118–124、緯度 20–27 做粗略範圍檢查，無效 294 件；這些事故仍保留在非地圖統計。地點僅統一字形與空白，不把不同方向的路口文字擅自合併成同一精確點。

## 重跑與驗證

執行 `python scripts/preprocess.py --years 2025` 可重建資料。完整表約 38.0 MB，原始事故 CSV 合計約 610.4 MB；本機一次完整批次實測約 60.3 秒，其他設備速度可能不同。

保留 360 個整案、887 列當事者的固定開發樣本；選取依案件 ID 雜湊順序、年度／城市／事故類別分層，不用來作正式統計。原始 ZIP 與完整生成資料均不提交 Git。

已檢查案件 ID 唯一、當事者 ID 唯一、外鍵完整、原始紀錄列數對得上各案紀錄總和、傷亡每案只計一次、兩種組距的直方圖總和與有效人次相同。單元測試包括同時同地兩案、順位重複但不同乘客、同案傷亡衝突、無效座標／時間、0 歲／非人／極端年齡與空資料。

網站驗證涵蓋六個入口、共用年度更新、5／10 歲組距、車種、待覆核值選項、空選與重設。重跑相同來源後，正式兩表與開發兩表 SHA256 相同。
